# Stock Volatility Prediction

An end-to-end machine learning project for predicting future stock volatility using historical market data.

## Tech Stack

- Python
- Pandas
- NumPy
- XGBoost
- PyTorch
- FT-Transformer (planned)
- SHAP
- PyArrow

## Pipeline

Download Data
→ Data Cleaning
→ Feature Engineering
→ Target Generation
→ XGBoost
→ FT-Transformer
→ Model Evaluation
